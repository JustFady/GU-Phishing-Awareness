Training Notes

This page replaces the old server-side log viewer. GitHub Pages serves static files only, so the project no longer collects, stores, displays, or downloads submitted data.

Before You Type

Check the address bar, page context, and whether the request was expected. Password reset prompts should come from known university systems.

Signals To Question

Urgency, unfamiliar links, odd wording, and credential requests after clicking email links are common signs of phishing.

What This Site Does

The simulation uses client-side navigation only. There is no Flask app, no log file, no Docker service, and no credential capture.
